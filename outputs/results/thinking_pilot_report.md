# Thinking Level Pilot Results

**Date run:** 2026-01-15
**Model:** gemini-3-flash-preview
**Pilot version:** 1.0.0

## Overview

This pilot tested three thinking levels (`minimal`, `low`, `high`) to determine the optimal reasoning depth for Gemini 3 Flash on the mound detection task. Each level was run 10 times on 20 calibration tiles (600 total API calls).

## Performance Summary

| Thinking Level | Mean Detections | SD | Mean Latency | Latency SD |
|----------------|-----------------|-----|--------------|------------|
| minimal | 64.0 | 5.2 | 34.2s | 27.1s |
| low | 61.9 | 5.8 | 39.7s | 3.1s |
| high | 63.6 | 10.7 | 97.3s | 10.1s |

### Detection Counts per Run

- **minimal:** [63, 64, 67, 65, 62, 63, 76, 62, 63, 55] (mean=64.0, sd=5.2)
- **low:** [66, 59, 61, 63, 75, 61, 52, 60, 61, 61] (mean=61.9, sd=5.8)
- **high:** [65, 73, 72, 59, 57, 57, 57, 61, 49, 86] (mean=63.6, sd=10.7)

### F1, Precision, and Recall (Bootstrapped 95% CIs)

**Ground truth:** 43 mounds across 20 calibration tiles

| Level | Precision | Recall | F1 | F1 SD |
|-------|-----------|--------|-----|-------|
| minimal | 0.402 [0.383, 0.417] | 0.595 [0.581, 0.609] | **0.479** [0.464, 0.492] | 0.023 |
| low | 0.396 [0.372, 0.419] | 0.565 [0.553, 0.579] | 0.465 [0.446, 0.483] | 0.031 |
| high | 0.391 [0.356, 0.423] | 0.567 [0.537, 0.593] | 0.460 [0.432, 0.486] | 0.044 |

**Method:** Count-based estimation (TP = min(detections, ground_truth) per tile).
Bootstrap: 10,000 resamples, seed=42.

**Key observations:**
- All three levels have overlapping 95% CIs for F1
- Minimal achieves highest mean F1 (0.479) with lowest variance (SD=0.023)
- High shows nearly 2× the F1 variance of minimal (0.044 vs 0.023)
- Precision is low (~0.40) due to over-detection; recall is moderate (~0.57-0.60)

### Key Findings

1. **Detection performance is statistically equivalent across all three levels**
   - Range: 61.9 - 64.0 (difference of 2.1 detections, 3.3% of mean)
   - This difference is well within run-to-run variance

2. **Latency increases significantly with thinking level**
   - minimal → low: 1.16x slower
   - minimal → high: 2.84x slower (nearly 3x)

3. **High thinking level shows HIGHER variance, not lower**
   - High SD=10.7 vs minimal SD=5.2
   - This is counter-intuitive: more reasoning produces less consistent results
   - Suggests the task is fundamentally visual pattern matching, not reasoning

4. **Cost implications**
   - High thinking uses ~3x the compute for no benefit
   - For 1,960 tiles in main experiment at K=10: 58,800 API calls
   - Using minimal instead of high saves ~2x the latency cost

## Decision Analysis

Per the spec decision criteria (using F1 metrics):

| Criterion | Result |
|-----------|--------|
| high >> low (F1 diff > 0.05) | No — F1 diff = -0.005 (high is slightly worse) |
| high ≈ low (F1 diff ≤ 0.03) | **Yes** — F1 diff = 0.019, CIs overlap |
| low > high | Marginally — low F1 (0.465) > high F1 (0.460) |
| minimal ≈ low | **Yes** — F1 diff = 0.014, CIs overlap |
| minimal > others | **Yes** — minimal F1 (0.479) is highest with lowest variance |

## Recommendation

**Use `minimal` thinking level for the main experiment.**

Rationale:

1. Minimal achieves the highest F1 (0.479) of all three levels
2. Minimal has the lowest variance (F1 SD=0.023 vs 0.044 for high)
3. Minimal is 2.84× faster than high (34.2s vs 97.3s per 20 tiles)
4. All CIs overlap — differences are not statistically significant
5. Visual pattern matching does not benefit from extended reasoning

This finding aligns with the hypothesis that mound symbol detection is primarily a perceptual task rather than a reasoning task. The model either recognises the "sunburst" pattern or it doesn't - additional reasoning steps don't improve pattern recognition.
