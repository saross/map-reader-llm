# Issue Tracking — Resolved

**Status**: archived. Issue and bug-tracking artefacts where the underlying issues have been resolved.

## What goes here

- Resolved bug / fix lists.
- Software-fix inventories whose items have all been implemented.
- Issue-triage documents from completed triage cycles.

## What does NOT go here

- Active bug trackers (stay in `planning/` or as GitHub issues).
- Implementation details or commits (those live in `scripts/` + git history).
- Pre-launch audits (separate bucket).

## Relationship to other archive subdirs

- `archive/implemented-instructions/`: design specs for features that were then implemented; closely related but different focus (specs vs bug lists).
- `archive/deprecated-scripts/`: old script versions.

## How to retrieve

Each file has a SUPERSEDED banner identifying when resolution completed.
