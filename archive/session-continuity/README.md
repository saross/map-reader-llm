# Session Continuity Documents

**Status**: archived. Session-scoped handoff documents (investigation notes, continuity memos) from closed sessions. Preserved for the historical record of how in-progress investigations unfolded across sessions.

## What goes here

- Single-session investigation continuity docs that have been superseded by consolidated findings elsewhere (typically in working-notes Obs entries or dedicated analysis reports).
- Session handoff memos where the work has since been completed.

## What does NOT go here

- Active continuity docs (`planning/paper-writeup-continuity.md` stays in `planning/` while the paper write-up is active).
- End-of-session reflections (those live in `docs/notes/reflections/session-reflection.md` as a continuous living doc).
- Pilot or investigation outputs (go under `archive/outputs-*-*` as appropriate).

## Relationship to other archive subdirs

- `archive/cc-sessions/`: Claude Code session transcripts (JSONL); separate from these handoff docs.
- `archive/pre-toolkit-reflections/`: older reflection-style docs; a reflection vs continuity-handoff is a format difference, not a content difference.

## How to retrieve

Each file moved into this directory has a SUPERSEDED banner at the top with (a) the date of supersession, (b) the reason, and (c) where the findings landed (working-notes Obs number / analysis report).
