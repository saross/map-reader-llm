# Infrastructure and Operations Planning

**Status**: archived. Infrastructure, migration, and operational planning documents that have been either executed or superseded by active plans elsewhere.

## What goes here

- Migration plans (repo, data, compute) that are complete or replaced.
- Stage-N progress reports for multi-stage infrastructure projects where later stages have completed.
- Deployment / CI / tooling plans whose implementation is finished.

## What does NOT go here

- Active infrastructure plans (e.g., a migration plan that is the current working doc stays in `planning/`).
- Configuration files or scripts (separate: `archive/deprecated-configs/`, `archive/deprecated-scripts/`).
- Code implementation files.

## Relationship to other archive subdirs

- `archive/implemented-instructions/`: software-feature specs; distinct focus.
- `archive/cc-sessions/`: Claude Code transcripts.

## How to retrieve

Each file has a SUPERSEDED banner identifying either the replacement doc or the current active plan.
