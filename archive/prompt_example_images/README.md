# Archived Prompt Example Images

**Originally located in**: `inputs/calibration-run/` (renamed to `prompt_examples` then archived).

These images were manually collected during the V3 calibration phase (Dec 2024) to create few-shot examples for the prompt. They includes verified examples of:

*   **False Negatives (`fn_...`)**: Mounds that were missed (e.g., obscured by contours).
*   **False Positives (`fp_...`)**: Objects incorrectly identified as mounds (e.g., blobs hitting contour lines).
*   **Reference Benchmarks**: High-confidence examples.

These are preserved here for historical reference on how the V3 prompt was tuned.
