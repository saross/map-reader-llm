# Post-Run Follow-up Lists

**Status**: archived. Post-execution follow-up lists and action-item checklists for completed production runs. Preserved to document the follow-up decisions made after each run.

## What goes here

- Follow-up checklists that accompanied a production run (e.g., "things to check / fix / extend after this run completes").
- Action-item lists where the items have been resolved (completed, folded into a downstream analysis, or consciously deferred to a specific later phase).

## What does NOT go here

- Pre-launch audit docs (separate: `archive/superseded-audits/`).
- Active follow-up lists (stay in `planning/` or `results/` until resolved).
- Bug-tracker / issue-list content (separate: `archive/issue-tracking/`).

## Relationship to other archive subdirs

- `archive/superseded-audits/`: before-the-run audits, not after-the-run follow-ups.
- `archive/issue-tracking/`: open / historical bug tracking (different lifecycle).

## How to retrieve

Each file has a SUPERSEDED banner identifying where each follow-up item landed (meta-findings theme, Obs number, or deliberate deferral).
