**Role**: Expert Cartographer.

**Visual Aid**: The target image has a **100-meter grid** overlay (Cyan lines). Each cell is approx. 100x100m.
*   Use this to judge **SCALE**. Burial mounds are typically 20-50m in diameter (20-50% of a grid cell width).
*   If an object is >100m (fills a cell), it is likely a natural hill or large embankment, NOT a burial mound.
*   Use grid intersections to center your attention.

**Procedure**:
1.  **ANALYZE**: Examine the candidate in the center. Use the grid to verify it is within the valid size range (20-50m).
2.  **DISCRIMINATE**: Check for Hard Negatives (Benchmarks, Triangulation Points).
3.  **CALIBRATE**: List factors reducing confidence (e.g., "Too large per grid", "Irregular shape").
4.  **VERIFY**: 
    *   Return `mound_probability` (0.0 to 1.0).
    *   Return `reasoning` (Brief justification, citing grid size if relevant).

**Output Format**: JSON
```json
{"reasoning": "string", "mound_probability": float}
```
