# OSF Registration Narrative Summary

This registration contains preregistration documents for a study evaluating vision-language model (VLM) prompting strategies for cartographic symbol detection. The preregistration specifies:

1. **Hypotheses**: Eight confirmatory hypotheses (H1–H8) testing modality and text elaboration, two-stage pipeline architectures, consensus voting, example ordering, negative text treatment, cross-model transfer, temperature, and library composition. Seven exploratory hypotheses (H9–H15) are also documented.

2. **Data resources**: A 361-tile corpus from four Soviet 1:50,000 topographic maps of Bulgaria, with 20 tiles allocated to prompt development (contaminated), 60 tiles as the holdout evaluation set, and 281 tiles reserved for future confirmatory testing.

3. **Analysis plan**: Symbol-level F1 as the primary outcome, tile-level Matthews Correlation Coefficient as secondary, with bootstrap confidence intervals and False Discovery Rate correction at q = 0.05.

4. **Companion materials**: Complete prompt text and configurations (Appendix), factorial coverage matrix, and tile selection manifests with random seeds.

This registration is the first one for this project. Preliminary work informed hypothesis formulation — this exploratory analysis is explicitly documented in the preregistration to maintain transparency regarding the distinction between exploratory development and confirmatory testing.
