# Documentation

Start with the guide that matches your task:

- [Agent guidance](agent-guidance.md): shared project policy, research conventions,
  preservation, and compute requirements.
- [Collaboration handoffs](collaboration-handoff.md): prepare a change for review
  or continuation, with exact sources, evidence, checks, and outstanding decisions.
- [Pipelines](pipelines.md): the analysis workflows and their methodology.
- [User guide](user-guide.md): script usage, prompt configuration, and data management.
- [Tests](../tests/README.md): test tiers and validation guidance for code changes.

Before running an experiment, follow the current execution plan and the approval
requirements in the shared project guidance.
